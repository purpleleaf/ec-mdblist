## Italiano

Benvenuto su **Mdblist Translator**, l'addon ponte progettato per integrare le tue liste personalizzate su Stremio.

### 💡 Cos'è MDBList?
**MDBList** (Movie Database List) è un potente servizio online che ti permette di creare liste automatiche e personalizzate di film e serie TV. Puoi filtrare i contenuti usando un'infinità di criteri, come i voti di IMDb, Rotten Tomatoes o Metacritic, l'anno di uscita, la popolarità, le piattaforme di streaming, i generi e molto altro.

### 🔌 A cosa serve questo Addon?
Questo addon è stato progettato come **ponte (bridge)** tra il sistema di configurazione di **easyCatalog** e le tue liste di **MDBList**. Ti permette di convertire e mostrare i cataloghi generati su MDBList direttamente all'interno di Stremio come cataloghi fluidi, reattivi e sempre aggiornati. Può ovviamente essere usato autonomamente, ma l'integrazione in EasyCatalog è caldamente consigliata.

### 🛠️ Come installarlo su Stremio
L'installazione è semplicissima ed è guidata dall'interfaccia web di questo Space:

1. **Copia l'URL del Manifest**: Clicca sul pulsante di installazione nell'interfaccia web di questo Space oppure copia l'indirizzo internet diretto che termina con `/manifest.json` (es. `https://IL_TUO_SPACE.hf.space/manifest.json`).
2. **Apri Stremio**: Avvia Stremio sul tuo dispositivo (PC, Smartphone, TV).
3. **Incolla l'URL**: Vai nella sezione **Add-on**, incolla l'URL appena copiato all'interno della barra di ricerca in alto e clicca sul pulsante **Installa**.

## English

Welcome to **Mdblist Translator**, the bridge addon designed to integrate your custom lists into Stremio.

### 💡 What is MDBList?
**MDBList** (Movie Database List) is a powerful online service that allows you to create automated and highly customized lists of movies and TV shows. You can filter content using a vast array of criteria, including IMDb, Rotten Tomatoes, and Metacritic ratings, release year, popularity, streaming platforms, genres, and much more.

### 🔌 What does this Addon do?
This addon was developed to act as **bridge** between the **easyCatalog** configuration system and your **MDBList** accounts. It allows you to convert and display the catalogs generated on MDBList directly inside Stremio as smooth, responsive, and automatically updated catalogs. It can obviously be used as a standalone catalog but we strongly encourage embedding it in Easycatalog.

### 🛠️ How to install it on Stremio
Installation is extremely straightforward and guided by this Space's web interface:

1. **Copy the Manifest URL**: Click the install button on this Space's web interface or copy the direct web address ending with `/manifest.json` (e.g., `https://YOUR_SPACE.hf.space/manifest.json`).
2. **Open Stremio**: Launch Stremio on your device (PC, Smartphone, Android TV).
3. **Paste the URL**: Go to the **Add-ons** section, paste the copied URL into the search bar at the top, and click the **Install** button.
